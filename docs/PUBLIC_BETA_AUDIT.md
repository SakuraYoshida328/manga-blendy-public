# 一般公開ベータ候補の監査

対象 `v0.1.0-beta.1`、2026-10-12。**判定：機能制限と未検証を明記したソース配布ベータとして、条件付きで公開準備可能。公開は未実施。** 所有者による公開先・ライセンス・権利・候補内容の最終承認が必要です。

## 分離と保全

- Private開発リポジトリを変更せず、現在のソースから必要ファイルだけを抽出した独立候補です。古い`.git`をコピーせず、新しい公開用履歴を作ります。
- 原稿・私的画像・既存制作資料・大型.blend・生成ログ・config.json・.venv・認証ファイル・内部監査資料を配布しません。
- 作例の例外は、手定義fixtureからの公開用PNG5枚だけ。provenance.jsonに出自・ハッシュを記録。個人の成功作例は使いません。
- Python本体の変更はバージョン定数のみ。公開候補のPS1をUTF-8 BOM付きに変更。開発環境と成功済みの背景生成データは維持。
- ソースとGit履歴、PNGメタデータ、配布ZIPを秘密情報・個人用パスについて検査します。数値と結果は `audit-data.json` と `SOURCE_MANIFEST.json`。検査で未知の権利者まで自動判定できるとは扱いません。

## ライセンス

GPL-3.0-or-later案。Blender公式のbpy公開スクリプト方針に合わせた提案です。MCPは検証した固定コミットのMIT原文と著作権表記を保存。通常31依存・任意認証4依存に加え、検証Blender内のrequests関連5配布物のメタデータと原文を記録しています。Blender／MCP／Python／wheelは同梱しません。[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) を参照。

## 実機未検証・公開後に確認する項目

- 別Windows PCの空OS環境。Python／Git／PowerShell／Blender公式ZIPの新規導入、MCPの新規GUI導入とrequests不足時の追加導入。
- Python 3.14でのアプリ実行。固定依存解決のみ確認済み。Windows 10、ARM64、最低スペックPC、他Blender版。
- 別利用者の初回ChatGPTログイン、利用枠・地域・組織制限。今回の実認証／モデル一覧再取得は未実施。
- 公開GitHubの匿名clone／Releaseダウンロード、Issueフォームの実表示、非公開脆弱性報告の設定。Public化前には試せない。
- 新しい利用者画像からの複雑な背景の外観品質。公開作例は構造試験で、完成漫画の質感を保証しない。

## 広告と機能の境界

完全自動の画像解析と漫画仕上げは未実装。外部Codex／ChatGPTからJSON／PNGを取り込む支援アプリです。ChatGPTログインはモデル一覧の接続試験であり、自動画像生成を有効化しません。本人のアカウントを使い、有料API・追加クレジットへ自動切替しません。外部アプリの残量自動取得も未実装で、枠切れなら外部工程を停止します。

上記を説明せず「画像1枚で完成漫画背景を全自動生成するアプリ」と紹介する準備はできていません。導入支援・設定資料化・構造再利用・外部仕上げ連携を試す公開ベータとして紹介してください。
