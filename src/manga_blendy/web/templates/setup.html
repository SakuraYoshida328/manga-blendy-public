初回導入と接続診断

方式を勝手に切り替えません。APIキーは不要です。利用枠がなくなれば外部AI処理を停止し、保存した資料を使います。本体へのPlus自動解析と画像生成は未対応です。



Blender・MCPを準備する
  1. Blender未導入の場合は公式配布元から5.2を手動で導入し、上の実行ファイルを指定します。
  2. 既存のBlender MCPアドオンを有効にし、アドオンの接続サーバーを起動します。
  3. 127.0.0.1:9876を待ち受ける設定にして、上の接続確認を実行します。
  4. 新しい背景を出すときだけMCP接続が必要です。閲覧・保存画像の利用では起動しません。
アプリはBlenderやMCPを自動インストールしません。未導入の環境では同梱の導入手順を参照してください。


AI機能の現在の範囲
解析は元画像と観測JSON、仕上げは構造PNGと画風参照の受け渡し方式です。仕上げZIPには固定指示とカメラ・部品情報が入り、過去の会話履歴を使わず同じ入力を渡せます。
同梱の「ChatGPTログイン.cmd」は従来のログイン・モデル一覧の接続試験です。ログイン成功だけでは画像編集が実行可能になりません。公式の利用範囲を確認できます。
